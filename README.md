# Jogo do Sonic

Um jogo estilo endless runner inspirado no clássico jogo do dinossauro do Chrome, mas com o Sonic como protagonista.

## Características

- **Personagem**: Sonic com animações de sprite sheet
- **Inimigos**: 
  - Crabmeat (terrestre) - com animação de caminhada
  - Buzz Bomber (aéreo) - com animação de voo
- **Sistema de vidas**: 3 vidas iniciais
- **Power-ups**: Escudo e vida extra
- **Ciclo dia/noite**: Mudança automática de cenário
- **Pontuação**: Sistema de high score com localStorage

## Como jogar

- **Espaço**: Pular
- **P**: Pausar/Retomar
- **Objetivo**: Evitar obstáculos e coletar power-ups

## Tecnologias

- HTML5
- CSS3 (Animações e sprites)
- JavaScript (Vanilla)
- Flask (Backend)

## Como executar

```bash
python app.py
```

Acesse: http://localhost:5000
